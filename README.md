# Sentinel AI — Demonstration of ChatBot using OpenAI

Sentinel AI is an intelligent digital safety platform and AI-powered chatbot designed to detect harmful interactions, explain risks, and guide young users (Gen Z and Gen Alpha) with practical safety steps.

---

## Quick Start Guide

### 1. Install Dependencies
Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed, then run:
```bash
npm install
```

### 2. Configure Your OpenAI API Key
Create a `.env` file in the project root (you can copy `.env.example`):
```bash
cp .env.example .env
```
Open `.env` in any text editor and paste your OpenAI API key:
```env
OPENAI_API_KEY=your_actual_openai_key_here
OPENAI_MODEL=gpt-4o-mini
PORT=3000
```
> **Security Note:** Never commit your `.env` file or API key to version control. The `.gitignore` file is configured to keep it secure.

### 3. Start the Application
On Windows, check whether port 3000 already has a listener before starting another server:
```powershell
$listener = Get-NetTCPConnection -LocalPort 3000 -State Listen -ErrorAction SilentlyContinue | Select-Object -First 1
if ($listener) {
  Write-Host "Port 3000 is already in use by PID $($listener.OwningProcess). Check the existing app instead of starting a duplicate."
  Invoke-RestMethod http://localhost:3000/api/status
} else {
  npm start
}
```
If the status request identifies Sentinel AI, open the existing server at **http://localhost:3000/**. Do not start `npm start` again while it is running.

On other operating systems, or after confirming the port is free:
```bash
npm start
```
The server will start on [http://localhost:3000/](http://localhost:3000/). Keep that terminal open while using the app.

### 4. Open in Your Browser
Open http://localhost:3000/ in Chrome, Edge, or Firefox.
This Express URL is recommended. If you open the page through VS Code Live Server on another local port (for example, `http://127.0.0.1:5500`), the frontend sends its API requests to the Sentinel AI backend on port 3000 rather than to Live Server.

## Features
- **OpenAI-Powered Chatbot:** Context-aware digital safety counselor providing supportive advice, boundary-setting drafts, and reporting instructions.
- **Quota Demo Mode:** If OpenAI specifically reports exhausted credits or quota, the chatbot can show clearly labelled sample safety advice. Demo replies are not generated by OpenAI; other API failures remain visible errors.
- **Multi-Turn Context:** Remembers previous questions and answers during your session for natural follow-up dialogue.
- **Interaction Analyzer:** Analyzes user-pasted messages for cyberbullying, predatory grooming, scams/phishing, and physical threats.
- **Dynamic Safety Dashboard:** Real-time metrics tracking interactions analyzed, average model confidence, and risk counts stored privately on-device.
- **Safety Incident Report:** One-click incident assessment reports with unique reference ID, evidence signals, Copy to Clipboard, and Print/Save as PDF options.
